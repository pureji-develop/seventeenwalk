# 04. ルーム管理と通信モデル

## 全体構成

```
HTTP
 ├── POST /rooms          → Hub.CreateRoom
 ├── GET  /rooms/:id      → 空き状況（任意）
 └── GET  /ws             → upgrader → Hub.Join → Client

Hub
 └── map[roomID]*Room

Room
 ├── id
 ├── game *game.Game
 ├── clients map[playerID]*ws.Client
 └── mu

Client
 ├── conn *websocket.Conn
 ├── send chan []byte
 ├── playerID / roomID / seat
 ├── readPump()   // 受信 → Room.HandleMessage
 └── writePump()  // send → WebSocket 書き込み
```

## コンポーネント責務

| コンポーネント | 責務 |
|---------------|------|
| **Hub** | ルーム生成・検索・空ルーム削除。接続の振り分け |
| **Room** | 定員2の管理。メッセージを Game に適用し、マスク済み state を配信 |
| **Game** | 十七歩ルール・遷移・和了判定・得点加算。I/O 非依存 |
| **Client** | 1 WS 接続の read/write 分離 |

## 並行性ルール

1. **Write は Client あたり1 goroutine のみ**（`writePump`）  
   他ゴルーチンは `client.TrySend(msg)` で `send` チャネルへ送る。
2. **Room / Game の状態変更は Room.mu（または Game.mu）で直列化**  
   両者が同時に `submit_hand` / `discard_tile` しても順序付けされる。
3. **ブロードキャスト**  
   `Game.Apply` 成功後、各 Client に `protocol.BuildState(game, viewerSeat)` を個別送信。
4. **チャネル満杯時**  
   `send` がブロックし続ける場合は切断扱い（遅いクライアント保護）。

## 接続ライフサイクル

```
1. POST /rooms → roomId
2. ClientA: WS connect (roomId, name) → seat0, welcome + state
3. ClientB: WS connect → seat1, welcome + state(LOBBY)
4. 両者 ready → DEAL →（自動ドラ）→ BUILD → WALK → …
5. 切断:
   - LOBBY → 席解放
   - 対戦中 → 席を保持し `OPPONENT_DISCONNECT` + `connected=false`。約45秒以内に同一 `playerId` で再接続可
   - 猶予超過 → 相手勝ちで `OPPONENT_LEFT` + `GAME_OVER`
6. 明示 `leave` → 即退出（対戦中は相手勝ち）
7. 両者切断かつ猶予なし → Hub が Room 削除
```

## メッセージ処理フロー

```
readPump
  → json.Unmarshal(Envelope)
  → Room.HandleMessage(client, env)
       → Game.Apply(seat, action) (error | effects)
       → 成功:
            各 event ごとに seq++ して全員へ
            state は **1回だけ** seq++ し、同一 seq で各 client に MaskedState
       → 失敗:
            送信元のみ error
```

## 第1版でやらないこと

- 観戦
- マッチメイキングキュー（ルームID共有のみ）
- DB / リプレイ保存
- ロンの手動宣言・見逃し（`pass`）
- 赤ドラ・食い断などローカル役の細かいバリエーション選択 UI

※ 短い切断に対する再接続（`playerId` + 猶予）と BUILD 強制提出は実装する。

## HTTP API（最小）

### `POST /rooms`

Response `201`:

```json
{ "roomId": "r_01HXYZ..." }
```

### `GET /rooms/{roomId}`（任意）

```json
{ "roomId": "r_...", "players": 1, "phase": "LOBBY" }
```

### `GET /ws?roomId=&name=`

- 成功: WebSocket へアップグレード → `welcome`
- 失敗: HTTP 4xx（満室・不存在）
