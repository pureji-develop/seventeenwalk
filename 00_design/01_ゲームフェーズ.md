# 01. ゲームフェーズ仕様

## フェーズ一覧

| Phase 定数 | 値 | 説明 | クライアント待ち |
|------------|-----|------|------------------|
| `PhaseLobby` | `LOBBY` | ルーム作成〜2人揃い・ready 待ち | `join` / `ready` |
| `PhaseDeal` | `DEAL` | 136枚シャッフル・34×2配牌・脇山68確定 | なし（自動） |
| `PhaseDoraSelect` | `DORA_SELECT` | （互換用）通常は配牌直後に自動選定して `BUILD` へ | — |
| `PhaseBuild` | `BUILD` | 各34枚から13枚の手牌を組む | `submit_hand` |
| `PhaseWalk` | `WALK` | 捨て合い（最大17巡×2） | `discard_tile` |
| `PhaseRoundEnd` | `ROUND_END` | 和了/流局の結果表示 | `ack_round` |
| `PhaseGameOver` | `GAME_OVER` | マッチ決着 | `rematch` / `leave` |

## 遷移図

```
LOBBY
  │  players==2 かつ両者 ready
  ▼
DEAL ──────────────────────────────────────────┐
  │ 各34枚・脇山68枚確定                         │ 次局もここへ
  ▼                                              │
DORA_SELECT                                      │
  │ 先行がドラ表示牌を選択                       │
  ▼                                              │
BUILD                                            │
  │ 両者 submit_hand（各13枚）完了               │
  ▼                                              │
WALK                                             │
  │ discard を交互に進行                         │
  ├─ 合法ロン成立 ──► ROUND_END（和了）          │
  │ 両者17巡切り切り（流局）                     │
  ▼                                              │
ROUND_END                                        │
  │ 両者 ack_round                               │
  ├─ マッチ継続条件を満たす ──► DEAL              │
  └─ 決着 ──────────────────► GAME_OVER          │
                                                 │
（上記 DEAL ループ）◄────────────────────────────┘
```

## 用語

| 用語 | 意味 |
|------|------|
| 局（round） | 配牌〜和了/流局まで。1〜`totalRounds` |
| 先行（seat lead） | その局の東家。ドラ選定・第1打 |
| 後攻 | 西家 |
| 配牌34（wall） | 自分だけが見る34枚 |
| 手牌（hand） | 選んだ13枚 |
| 候補（pool） | 手牌に使わなかった21枚＝捨て候補 |
| 河（river） | 切った牌の列（公開） |
| 巡（turnIndex） | 0〜16。各プレイヤー最大17打 |

## マッチ設定（第1版デフォルト）

| 項目 | 値 |
|------|-----|
| `scores` 初期値 | 両者とも **0** |
| `totalRounds` | 規定対局数（4 / 6 / 8 / 10、デフォルト 4） |
| `buildLimitSec` | **180**（デフォルト3分。設定で変更可。タイムアウトで強制提出） |
| 和了加点（表示） | 満貫 +1 / 跳満 +1.5 / 倍満 +2 / 三倍満 +3 / 役満 +4 / ダブル役満 +8 / トリプル役満 +12（役満数×4） |
| 和了加点（内部） | 上記×2（+2 / +3 / +4 / +6 / +8 / +16 / +24 …） |

### 得点ルール（確定）

- **両者とも0点持ちで開始**する（内部 `scores=[0,0]`）。
- **加点のみ**とする。放銃者から点を移す・減点することはしない。
- 和了時: 和了者の内部得点に ×2 整数を加算する。プロトコルでは `/2.0` の float で配信。
- 流局時: 得点変動なし。
- **決められた対局数（`totalRounds`）がすべて終了した時点**で、得点の高いほうを勝者とする。
- **同点終了時は引き分け**（タイブレーク・延長なし）。
- 和了条件の満貫判定は **翻数のみ**（**4翻以上**）。符計算は行わない。

### 先行（確定）

- 初局の先行（`LeadSeat`）はサーバがランダム抽選。
- **連荘なし**。毎局終了後に `LeadSeat` を交代し、`Round` を +1 する。
- **親子の概念なし**。点数は常に子の点数表。自風も両者西扱い。

### ドラ（確定）

- 脇山は **34スタック×上下2枚**。サーバがランダムにスタックを選び、**上牌を表ドラ表示牌**とする。
- 表ドラ = `NextKind(表表示牌)`。
- **裏ドラなし**（下牌は使用しない）。

### ダブル役満以上（確定）

- 役満は `YakumanCount`（1, 2, 3…）で持つ。ダブル役満以上を認める。
- 加点は 役満数×4（表示）。例: シングル+4、ダブル+8、トリプル+12。

### フリテン・満貫・自動ロン（確定・見逃しなし）

- **ロンの見逃しは仕様上存在しない**（クライアントに `ron` / `pass` を出さない）。
- 捨て牌が相手の和了形を完成させ、非フリテン、かつ**4翻以上**なら、**安目であってもサーバが即座に自動ロン**する。
- 和了形は完成するが**4翻未満**のロン牌だった場合:
  - その場ではあがらない（自動スルー）。
  - **以後すべての待ちでのあがりを放棄**（`AgariAbandoned=true`。フリテン同様、他の牌でもロン不可）して WALK を継続する。
- 通常フリテン: 相手の全待ちのいずれかが相手自身の河にあれば、一切ロン不可。

### BUILD タイムアウト（確定）

- BUILD 開始時にサーバが期限（デフォルト **180秒**）を設定する。`BuildTimerEnforced=true` のとき期限切れで強制提出する。
- 期限内に `submit_hand` しないプレイヤーは、`Wall` 先頭13枚を `Hand`、残り21枚を `Pool` として強制提出し、両者が揃い次第 WALK へ進む。

## 遷移条件（詳細）

### LOBBY → DEAL

- 条件: `len(players) == 2` かつ両プレイヤー `Ready == true`
- 副作用:
  - `Round = 1`
  - `LeadSeat` をランダム（0 or 1）
  - `scores = [0, 0]`（加点のみ・減点なし）
  - rematch 時も同様にリセット

### DEAL → BUILD（自動ドラ）

- 条件: 136枚をシャッフルし以下を確定
  - `Players[i].Wall` … 各34枚（非公開）
  - 脇山からランダムに表ドラ表示牌を自動選定（`DoraIndicator` / `DoraKinds`）
- 副作用:
  - `Hand` / `Pool` / `River` をクリア
  - **即 `BUILD`**（通常プレイでは `DORA_SELECT` を経由しない）
  - **BUILD 期限設定**（デフォルト180秒。`BuildTimerEnforced=true` で強制提出）

### `DORA_SELECT`（互換）

- 手動 `select_dora` 用のフェーズ。現行の配牌フローでは使わない。

### BUILD → WALK
- 条件: 両者が `submit_hand` 済み、**またはタイムアウトによる強制提出で両者が揃った**
- 検証（通常提出）:
  - ちょうど13枚
  - すべて自分の `Wall` に含まれる（重複・他牌不可）
  - 第1版は1回のみ提出
- タイムアウト強制:
  - 未提出 seat について `Hand = Wall[0:13]`, `Pool = Wall[13:34]`
- 副作用:
  - タイマー停止
  - `ToAct = LeadSeat`
  - `TurnCount = [0, 0]`
  - リーチ状態を両者 true（常時）

### WALK → ROUND_END

#### 捨て規則

- 手番プレイヤーは自分の `Pool` から1枚を選んで切る（`discard_tile`）
- 切った牌は `Pool` から除去し、自分の `River` 末尾に追加
- `TurnCount[seat]++`
- 第1打（各プレイヤーの turnIndex==0）でもリーチ宣言演出可（ルール上は最初からリーチ）

#### ロン判定（サーバ・自動・見逃しなし）

捨て完了直後、相手（非打牌者）について:

1. 相手手牌13 + 捨て牌 で和了形か
2. **通常フリテンでないか**（相手の全待ちのいずれかが相手自身の河に含まれる → 和了不可）
3. **あがり放棄済みでないか**（4翻未満ロン牌を一度受けた後は全待ち放棄）
4. 役を数え（**表ドラ含む。裏ドラなし**）、**4翻以上**か（リーチ+1翻・一発・河底等。**符は見ない**）
5. 役満は `YakumanCount`（ダブル以上可）
6. 4翻以上 → **安目でも即自動ロン** → `ROUND_END`（`result=RON`）
7. 和了形だが4翻未満 → 和了せず、**全待ちあがり放棄**して WALK 継続

`pass` / 見逃し操作は存在しない。

#### 一発・河底

| 条件 | 役 |
|------|-----|
| 先攻・後攻どちらの**第1打**であがった（立直前でも可） | 一発 |
| **後攻**の第17打（最終打）であがった | 河底撈魚 |

※常時リーチのため、リーチ供託・河の横向き表示は行わない。

#### 流局

- 条件: ロンなしで両者が17枚すべて切り終わった（`TurnCount` がどちらも17、または両 `Pool` が空）
- → `ROUND_END`（`result=DRAW`）

### ROUND_END → DEAL または GAME_OVER

1. 和了なら和了者へ加点のみ行い統計更新（敗者の得点は変えない）
2. 両者 `ack_round` を待つ（演出同期）
3. `Round >= totalRounds` なら `GAME_OVER`（高得点が勝ち。**同点は引き分け**）
4. さもなくば `LeadSeat` 交代・`Round++` し、手牌・河などをクリアして `DEAL` へ（**連荘なし**）

### 任意 → GAME_OVER（切断）

- 対戦中に一方が切断したら相手へ `OPPONENT_LEFT`、勝者＝残った側

### GAME_OVER からの復帰

- `rematch`: 両者同意後、得点を `[0, 0]`・局数を初期化し `DEAL` から再開
- `leave`: ルーム退出。第1版はルーム破棄

## 切断時

- 対戦中切断 → `GAME_OVER`（`WinnerSeat = 残ったプレイヤー`）
- LOBBY のみ → 席解放

## WALK サブ状態

フェーズは `WALK` のまま、`WalkState` で管理する。

| フィールド | 説明 |
|------------|------|
| `ToAct` | 手番 seat |
| `TurnCount[2]` | 各プレイヤーの打数 0–17 |
| `Rivers[2]` | 各プレイヤーの河 |
| （派生） | `legalTileIds` は自分の Pool 全牌（第1版は切禁なし） |
