# 05. Go ディレクトリ構成

```
backend/
├── go.mod
├── go.sum
├── cmd/
│   └── server/
│       └── main.go              # エントリポイント（HTTP + WS 起動）
└── internal/
    ├── game/                    # ルール・状態（I/O 非依存）
    │   ├── tile.go              # Tile / Kind / NextKind（ドラ）
    │   ├── deck.go              # 136枚生成・シャッフル・分割
    │   ├── evaluator.go         # 和了形・役・満貫・フリテン（集約）
    │   └── game.go              # Phase / Player / Apply / BUILD 180s
    ├── protocol/                # JSON エンベロープ・マスク済みビュー
    │   ├── envelope.go
    │   ├── action.go
    │   └── state.go
    ├── room/                    # Hub / Room（mutex 直列化）
    │   ├── hub.go
    │   └── room.go
    └── ws/                      # WebSocket Client
        └── client.go
```

## パッケージ依存方向

```
cmd/server
    → room, ws, protocol
room
    → game, protocol, ws
ws
    → protocol
protocol
    → game
game
    → （標準ライブラリのみ）
```

`game` は WebSocket / HTTP に依存しない。和了・役・フリテンは `evaluator.go` にまとめ、過度なファイル分割を避ける。

## 得点表現

| 層 | 表現 |
|----|------|
| `game.Player.Score` | `int`（実点×2。満貫和了で +2） |
| `protocol` JSON `scores` | `float64`（`Score/2.0`） |

## 実装時の優先コア

| パス | 内容 |
|------|------|
| `tile.go` / `deck.go` | 牌・山・`NextKind` |
| `evaluator.go` | 和了・役・満貫・フリテン |
| `game.go` | 遷移・BUILD タイムアウト・直列 Apply |
| `protocol/state.go` | マスク済み PublicState |
| `room/room.go` | WS 処理・ブロードキャスト |
