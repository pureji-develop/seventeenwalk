# SeventeenWalk バックエンド確定仕様概要

本ドキュメント群は、通信対戦・十七歩（じゅうななほ / 2人）のバックエンド実装前提となる確定仕様である。

## プロジェクト前提

| 項目 | 内容 |
|------|------|
| 言語 | Go |
| 通信 | WebSocket（JSON） |
| ポート | 8080（Docker） |
| 永続化 | なし（インメモリ、DB不使用） |
| 対戦 | 2人固定 |
| 勝利 | 規定対局数終了時の得点比較（両者0点スタート・加点のみ。詳細は [01](./01_ゲームフェーズ.md)） |
| 責務分離 | フロント（Phaser）は描画のみ。ロジック・状態・勝敗はすべてサーバ |

## 設計方針

1. **サーバが唯一の真実（source of truth）**  
   クライアントは受信した `state` を描画するだけとする。
2. **受信者ごとにマスクしたフルスナップショット**  
   差分パッチは使わない。相手の配牌34・手牌・捨て候補の中身は非公開（河・ドラ表示などは公開）。
3. **ロンはサーバが自動判定（見逃しなし）**  
   `ron` / `pass` 操作は持たない。  
   - その捨て牌で満貫以上になるなら、**安目であっても即座に自動ロン**する。  
   - 満貫未満（4翻未満）のロン牌なら和了せず、**以後すべての待ちでのあがりを放棄**して進行する（他牌でもロン不可）。
4. **ルーム単位の直列化**  
   1ルームのアクション適用は mutex で直列処理する。
5. **得点の内部表現は 2 倍整数**  
   跳満 +1.5 等の 0.5 刻みを誤差なく扱うため、`Game` 内はすべて `int`（実点×2）。JSON 出力時のみ `/ 2.0` の `float64` にする。

## 十七歩ルール要約（第1版）

| 項目 | 内容 |
|------|------|
| 牌数 | 標準136枚（萬・筒・索・字、各4枚）。赤ドラなし |
| 配牌 | 各プレイヤーに非公開34枚。残り68枚は脇山（ドラ選定用） |
| ドラ | サーバが脇山から**ランダム自動選定**。`NextKind` が表ドラ。**裏ドラなし** |
| 手組み | 34枚から13枚を選び手牌とする。残り21枚＝捨て牌候補。**BUILD 制限はデフォルト3分（設定変更可）**。未提出なら Wall 先頭13枚を強制提出（本番タイマー有効時） |
| 進行 | 先行から交互に候補から1枚捨て。最大各17巡 |
| 先行 | 初局はサーバがランダム抽選。**毎局交代**（連荘なし） |
| リーチ | 常時リーチ扱い（+1翻）。ダブルリーチなし。人和なし。**供託なし** |
| あがり | ロンのみ。**見逃しなし・自動ロン**。安目でも4翻以上なら即和了。4翻未満のロン牌は**全待ちあがり放棄**。ポン・チー・カン・ツモなし |
| 一発 | 先攻・後攻とも第1打のあがり（立直前でも可） |
| 河底 | 後攻の第17打であがり |
| フリテン | 待ち牌のいずれかが自分の河にあれば和了不可（通常フリテン） |
| 自風 | **親子なし**。自風は両者が西扱い（場風=東固定）。役牌は場風東・三元のみ＋自風西 |
| 役 | 通常麻雀の役のうち、鳴き・ツモ前提を除くものを採用。**ダブル役満以上あり**。実装は `game/evaluator.go` |
| 得点 | 両者0点開始・加点のみ。**親子差なし（常に子の点数）**: 満貫8000 / 跳満12000 / … / 役満32000×n（符計算なし・4翻以上）。規定対局数終了時に高得点が勝ち。**同点は引き分け** |

## 分岐点の確定（第1版）

| 項目 | 決定 |
|------|------|
| 先行決定 | 初局はサーバがランダム抽選。以降は**毎局交代**（連荘なし） |
| 局数 | ロビーで 4 / 6 / 8 / 10 から選択（既定 4） |
| ドラ選定 | サーバが脇山34スタックからランダム自動選定。表＝上牌（裏ドラなし） |
| 手組み検証 | 提出13枚が自分の34枚に含まれること。聴牌強制はしない |
| BUILD タイムアウト | デフォルト **180秒（3分）**（設定可）。期限切れで未提出は強制提出（`BuildTimerEnforced=true`） |
| 満貫判定 | 和了時。**4翻以上なら自動ロン**（符は見ない）。4翻未満のロン牌は**全待ちあがり放棄**（以後一切ロン不可） |
| ロン操作 | **見逃しなし**（`ron` / `pass` アクション自体が存在しない） |
| 役満 | シングル〜複数役満（ダブル以上）を `YakumanCount` で表現 |
| 得点内部 | ×2 整数。プロトコルは float |
| 再接続 | 非対応 |
| 再戦 | `rematch` で同ルーム再戦可 |
| 牌表記 | 種類は `"m5"`, `"ton"` 等。識別は数値 `tileId` |
