## 新規サブドメイン（新プロジェクト）デプロイ標準手順

### 1. メインNginx設定の追記 (`nginx.conf`)
`/srv/taimanpoker/nginx/nginx.conf` に、新プロジェクト用の upstream および 80/443 server ブロックを追加する。

---

### 2. 個別アプリコンテナの起動
新プロジェクトのディレクトリに移動し、共通ネットワーク (`shared-net`) に接続した状態でコンテナを起動する。

```bash
cd /srv/<新プロジェクト名>
git pull origin main
docker compose up -d
3. SSL証明書の取得 (Certbot)
メインプロジェクト側から Certbot を実行し、新サブドメインのSSL証明書を発行する。

Bash
cd /srv/taimanpoker
docker compose run --rm certbot certonly \
  --webroot -w /var/www/certbot \
  -d <サブドメイン名>.taimanpoker.com \
  --email hironori.kato.jp@gmail.com \
  --agree-tos --no-eff-email
4. メインNginxのテスト ＆ 反映
取得した証明書と設定変更をメインNginxに反映させる。

Bash
cd /srv/taimanpoker

# 構文チェック
docker compose exec nginx nginx -t

# 設定リロード (反映されない場合は docker compose restart nginx)
docker compose exec nginx nginx -s reload
補足：既存コンテナ更新時の注意事項
個別コンテナのイメージ更新（docker compose pull && docker compose up -d）を行った際は、Nginxの内部DNS再解決のため、仕上げにメイン側でNginxのリロードを実施すること。

Bash
cd /srv/taimanpoker
docker compose exec nginx nginx -s reload
