# SeventeenWalk（十七歩）プロジェクト

二人麻雀「十七歩（じゅうななほ / 17歩）」のオンライン通信対戦。

## バックエンド

- Go言語（標準ライブラリ）
- WebSocket
- API通信
- インメモリ。対戦結果などは保存しない。
- DBは利用しない。
- コンテナ利用。ポート番号：8080

## フロントエンド

- TypeScript + Vite
- WebSocket
- Phaser.js（3.x）
- 描画に徹する。
- コンテナ利用。ポート番号：5175（※5173/5174は他プロジェクトと衝突しやすい）
- シーン: Boot → Login → Lobby → Game / Credit

## ゲーム概要（要約）

- 2人対戦。各プレイヤーに34枚が配られ、その中から13枚の手牌（聴牌想定）を組む。制限時間は３分（設定で変更可能）
- 残り21枚が捨て牌候補。交互に最大17巡切り合い、ロンのみ（ツモ・鳴きなし）。
- ダブル役満以上あり。**連荘なし**（毎局先行交代）。**親子の点数差なし**（常に子の点数）。
- ドラはサーバが脇山からランダム自動選定。通常ゲーム同様、その次の牌がドラ（９→１に注意）。
- 常に初手リーチ扱い（+1翻）。人和なし。ダブルリーチなし。**リーチ供託なし**。**4翻以上**でなければあがれない（**符は見ない**）。裏ドラなし。
- 一発: 先攻・後攻とも**第1打**のあがり（立直前でも可）。河底: **後攻の第17打**であがり。
- **ロンの見逃しは無し**。たとえ安目でも、その牌で4翻以上になるなら**自動ロン**する。
- 4翻に届かないロン牌を切られた場合はあがれず、**以後「全ての待ちでのあがりを放棄」**して進行する。フリテンは他の牌でもロンできないため。
- フリテンあり。自分が切った捨て牌が自分の上がり牌である場合も、以後どの牌でもロンできない。
- 場風は東固定。**自風は両者とも西扱い**（親子なし）。
- 局数は 4 / 6 / 8 / 10 から選択。
- **得点**: 両者とも **0点スタート・加点のみ**（減点・移動なし）。規定対局数終了時に得点の高いほうが勝ち。**同点は引き分け**。
