# 06. フロントエンド構成

Phaser シーン構成。描画と入力送信のみ行い、ルール判定はしない。

## シーンフロー

```
BootScene → LoginScene ⇄ CreditScene
                ↓
            LobbyScene（ルーム作成/参加・準備）
                ↓  socket handoff（playerId 引き継ぎ）
            GameScene（描画のみ / 操作送信）
```

## GameScene 内の表示モード（phase 連動）

| phase | 主な表示 | 主な操作 |
|-------|----------|----------|
| `DORA_SELECT` | （互換）通常は即 `BUILD`。待ち表示のみ | — |
| `BUILD` | 自分の34枚・選択中の13枚（`BuildBoard` が選択差分更新） | `submit_hand` / `preview_waits` |
| `WALK` | 手牌・候補・両者の河・ドラ | `discard_tile` |
| `ROUND_END` | 和了役・得点加算 | `ack_round` |
| `GAME_OVER` | 勝者・最終得点 | `rematch` / `leave` |

牌画像は `public/tiles.webp` + `tiles.json` のスプライトを用いる（`kind` → 座標）。

## ネットワーク

- `NetworkManager`: 接続・送信・seq フィルタ・自動再接続（`playerId` を sessionStorage に保持）
- 未接続時の `send` は失敗を error イベントで通知
- 対戦中の相手切断は `opponent.connected === false` でバナー表示

## ディレクトリ

```
frontend/src/
├── main.ts
├── style.css
├── constants/     theme, network
├── network/       NetworkManager
├── scenes/        Boot / Login / Lobby / Game / Credit
├── types/         protocol.ts
├── game/          buildBoard, tileSprites（描画ヘルパ）
└── utils/         menuOverlay, tiles, yaku, …
```

## ローカル起動

```bash
# バックエンド
cd backend && go run ./cmd/server

# フロント（別ターミナル）
cd frontend && npm run dev
```

または `./start_local.sh`（docker compose）。

- フロント: http://localhost:5175
- API: http://localhost:8080
